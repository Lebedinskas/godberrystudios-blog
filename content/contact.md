# Contact

I'm Tomas, and Godberry Studios is just me. Emails come to my own inbox and I answer them personally — usually within a day or two.

**[hello@godberrystudios.com](mailto:hello@godberrystudios.com)**

## What people usually write about

**Something's broken, or a run failed.** Send me the Apify run ID (or a link to the run) and what you expected to get back. That's usually enough for me to reproduce it. If an actor charged you for a run that didn't deliver, tell me — I'd rather refund it than have you find out the hard way that I don't.

**"Can it also do X?"** Often yes, and if enough people ask for the same thing it goes in the next version. Feature requests from actual users are the only roadmap I trust.

**Custom or one-off scraping work.** Sometimes. Tell me the target, the volume, and the deadline and I'll tell you honestly whether it's a good fit or whether an existing tool does it better.

**Press, partnerships, or you're building something adjacent.** Happy to talk. If you're pitching a product for the blog, read [how I handle that](/posts/how-to-monetize-mcp-servers-2026/) first — I only write about tools I've actually run, and I publish what I find.
