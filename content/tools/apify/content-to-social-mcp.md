**This one didn't work out.** It shipped on 2026-04-12, found no paying users, and I stopped marketing it two weeks later. The listing stays online because a few people still run it, but it gets no new features and I wouldn't build on it today. I've written up [what it cost me and why](/posts/how-to-monetize-mcp-servers-2026/) — the plumbing was never the problem, the wedge was.

What it does, for the record: feed it a URL, an article, or raw text and it returns formatted posts for Twitter/X, LinkedIn, Facebook and more, in one call. It runs as an MCP server, so it plugs into Claude, ChatGPT, or any MCP-compatible client.

If you want something I actively maintain, start with the [Google Reviews Scraper](/tools/apify/google-reviews-scraper/) or the [Google Maps Leads Scraper](/tools/apify/google-maps-leads-scraper/).
